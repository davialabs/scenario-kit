---
title: Generate images
description: Use one visual style only when images are requested.
---

This step is optional and comes after delivering the final file. Only begin it
if the user explicitly asks you to generate one or more images.

The visual direction is not part of the scenario. Do not add it to `story` or
any other key in the final file. Generating a cover or scene must never change
the data that has already been validated.

## One style

Do not offer a choice of styles or invent one for each scenario. Always use
this same visual direction:

> Premium illustrated strategy-drama artwork in a clean graphic ink style:
> bold, slightly uneven black contours, simplified expressive forms, pale ivory
> paper, dry smoke-grey brush shadows, restrained cobalt accents and one muted
> coral accent. Human-scale, emotionally readable composition, flat
> hand-painted texture, no photorealism, no glossy concept-art finish, no
> generic AI polish.

Adapt only the subject, era, clothing, architecture, climate, and situation
shown. Do not change the graphic language, texture, or core palette.

## Build the requested image

If the requested image is unclear, ask only what should be generated: a cover,
a scene, or another specific visual. Then write a concrete description of the
moment, location, people present, and visible pressure before applying the
single style above.

Each image must be an original, readable composition with a clear main subject.
Do not add text, letters, numbers, logos, watermarks, interfaces, collages,
character grids, or borders.
